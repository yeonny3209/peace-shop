# 피스 상점

가족 공용화폐 **피스**로 운영하는 가정용 상점 웹페이지입니다. 문제집을 풀어 피스를 벌고, 상점에서 간식·게임시간·특권을 삽니다.

## 규칙

- 1피스 = 게임시간 10분 = 1,000원
- 수학 문제집 2장 = 1피스, 그 외 문제집 3장 = 1피스 (하루 상한 없음)
- 문제집 한 권 완주(오답까지) = +20피스, 엄마 승인
- 구매 요청은 엄마가 승인하면 잔액 차감 · 재고 1 감소, 잔액 부족·품절 시 구매 불가
- 모든 변동은 내역에 기록

안내 페이지: [guide.html](guide.html)

## 화면

- **상점(가족용)**: 가족 선택, 내 잔액, 상품 목록, 구매 요청, 문제집 완주 신고, 최근 내역
- **엄마 화면(비밀번호)**: 요청 승인/거절, 문제집 장수 입력 → 자동 적립, 완주 보너스, 가족·잔액 관리, 상품 추가/수정/삭제·재고, 내역, 설정

처음 비밀번호는 `1234`입니다. 엄마 화면 › 설정에서 바꿔 주세요.

## 서버 (공유 저장소)

`server.js`는 설치할 것이 없는 Node.js 서버입니다. 사이트를 보여주고, 잔액·상품·내역을 `data/state.json`에 저장해 모든 기기가 같은 데이터를 봅니다.

```bash
node server.js
```

Windows에서는 `start-server.bat`을 더블클릭해도 됩니다. 켜면 `http://localhost:3000`과 같은 와이파이의 가족 기기용 주소(`http://192.168.x.x:3000`)가 나옵니다.

- 서버를 켠 컴퓨터가 켜져 있어야 가족들이 접속할 수 있어요.
- 엄마 비밀번호는 서버에서 확인하고, 로그인하지 않은 가족은 구매 요청과 자기 요청 취소만 할 수 있어요.
- `data/`는 git에 올라가지 않아요. 백업하려면 이 폴더를 복사하세요.
- GitHub Pages 주소는 서버 없이 열리므로 이 기기에만 저장하는 모드로 동작해요.

## 기획서에서 정해지지 않은 항목의 기본값

| 항목 | 이 페이지의 기본값 |
| --- | --- |
| 남는 장수 처리 | 다음 입력에 이월 (설정에서 버림으로 변경 가능) |
| 간식 종류와 가격 | 예시 상품으로 시작, 엄마 화면에서 수정 |
| 피스 가족 간 송금 | 넣지 않음 |
| 환전 상품 | 분류만 준비, 상품은 없음 |
| 데이터 저장 방식 | 서버 공유 저장소 (서버가 없으면 localStorage) + 백업 파일 |
| 비밀번호 보안 수준 | 페이지 안에서 확인하는 가족용 잠금 |
| 재고 소진 시 | 품절 표시, 구매 요청 불가 |
