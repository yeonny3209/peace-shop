# 피스 상점

가족 공용화폐 **피스**로 운영하는 가정용 상점 웹페이지입니다. 문제집을 풀어 피스를 벌고, 상점에서 간식·게임시간·특권을 삽니다.

## 규칙

- 1피스 = 게임시간 10분 = 1,000원
- 수학 문제집 2장 = 1피스, 그 외 문제집 3장 = 1피스 (하루 상한 없음)
- 문제집 한 권 완주(오답까지) = +20피스, 엄마 승인
- 구매 요청은 엄마가 승인하면 잔액 차감 · 재고 1 감소, 잔액 부족·품절 시 구매 불가
- 모든 변동은 내역에 기록

안내 페이지: [guide.html](guide.html)

## 화면

- **상점(가족용)**: 가족 선택, 내 잔액, 상품 목록, 구매 요청, 문제집 완주 신고, 최근 내역
- **엄마 화면(비밀번호)**: 요청 승인/거절, 문제집 장수 입력 → 자동 적립, 완주 보너스, 가족·잔액 관리, 상품 추가/수정/삭제·재고, 내역, 설정

처음 비밀번호는 `1234`입니다. 엄마 화면 › 설정에서 바꿔 주세요.

## 데이터 저장

서버 없이 브라우저 `localStorage`에 저장합니다. 한 기기에서 쓰는 것을 기본으로 하며, 설정의 백업 파일 저장/불러오기로 다른 기기로 옮길 수 있습니다.

## 기획서에서 정해지지 않은 항목의 기본값

| 항목 | 이 페이지의 기본값 |
| --- | --- |
| 남는 장수 처리 | 다음 입력에 이월 (설정에서 버림으로 변경 가능) |
| 간식 종류와 가격 | 예시 상품으로 시작, 엄마 화면에서 수정 |
| 피스 가족 간 송금 | 넣지 않음 |
| 환전 상품 | 분류만 준비, 상품은 없음 |
| 데이터 저장 방식 | 기기 하나 (localStorage) + 백업 파일 |
| 비밀번호 보안 수준 | 페이지 안에서 확인하는 가족용 잠금 |
| 재고 소진 시 | 품절 표시, 구매 요청 불가 |
