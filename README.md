# 피스 상점

가족 공용화폐 **피스**로 운영하는 가정용 상점 웹페이지입니다. 문제집을 풀어 피스를 벌고, 상점에서 간식·게임시간·특권을 삽니다.

## 규칙

- 1피스 = 게임시간 10분 = 1,000원
- 수학 문제집 2장 = 1피스, 그 외 문제집 3장 = 1피스 (하루 상한 없음)
- 문제집 한 권 완주(오답까지) = +20피스, 엄마 승인
- 구매 요청은 엄마가 승인하면 잔액 차감 · 재고 1 감소, 잔액 부족·품절 시 구매 불가
- 모든 변동은 내역에 기록
- 가족 가상 회사 주식: 가족별 PIN으로 즉시 매수·매도

안내 페이지: [guide.html](guide.html)

## 피스 주식

가족 화면의 **주식**, 엄마 화면의 **주식 관리** 탭에서 사용합니다. 기존 데이터는 유지하며 처음에는 회사가 없는 상태로 시작합니다. 엄마가 회사 이름·소개·기준가를 등록하면 거래할 수 있습니다. 실제 이용 주소는 `https://peace-shop.onrender.com/#market`입니다.

- 가격은 기준가에 종목 자체 보유량 5주당, 이웃 종목별 합산 보유량 3주당, 시장 합산 보유량 5주당 각각 1피스를 더해 계산합니다. 각 주의 매수는 발행 직전 수량, 매도는 회수 직후 수량을 적용합니다. 같은 기준가에서 보유량을 원상복구하는 왕복 거래로 피스가 생기지 않습니다.
- 종목은 고리로 연결됩니다. 실적과 미션의 기준가 변화는 시작 종목에서 양쪽으로 퍼지고, 거리에 따라 줄어듭니다. 연동에 따른 종목별 다음 1주 매수가 변화는 그래프에 기록됩니다.
- 엄마는 회사 실적 또는 가족 미션의 결과와 사유를 입력해 기준가를 조정합니다. 기준가는 정수 1~10,000피스, 한 번의 조정은 -100~100피스입니다. 공부 적립은 별도로 기존 규칙을 따릅니다.
- 한 주문은 정수 1~100주입니다. 회사별 총 발행 수량은 10,000주까지입니다. 서버 모드에서 엄마가 가족별 거래 PIN을 한 번 설정하면 가족이 PIN으로 즉시 매수·매도할 수 있습니다. 기존 매수 PIN도 사용할 수 있습니다.
- 대기 매수 금액과 매도 주식을 예약합니다. 상품 구매·가족 송금에서도 같은 가용 잔액을 사용합니다. 취소·거절·가격 변경 만료 시 예약을 해제합니다.
- 승인 거래나 실적·미션 반영으로 회사 가격 조건이 변경되면 그 회사의 나머지 대기 주문은 만료됩니다. 바뀐 총액을 다시 확인하고 재요청해야 합니다.
- 서버가 가격, 권한, 잔액, 보유량을 검증하고 거래·원장·가격 버전을 하나의 상태로 저장합니다. 중복 승인과 동일 요청의 재전송은 중복 정산하지 않습니다.
- 주식 원가와 평가 손익은 참고값이며 평가액 자체는 피스 잔액이 아닙니다. 주식을 보유하거나 주문이 남은 가족은 삭제할 수 없습니다.

`stock-market.js`는 서버와 브라우저에서 공유하는 거래 규칙입니다. 기존 데이터에 `market`을 추가하며 Upstash 또는 로컬 저장 경로는 그대로 유지합니다. GitHub Pages는 계속 기기별 로컬 모드입니다. 주식 데이터를 포함한 전체 백업 복원·초기화는 엄마 인증과 상태 버전 검증을 거칩니다.

검증: `node --test test-market.js` (실제 가족 데이터 대신 임시 로컬 저장소 사용).

## 화면

- **상점(가족용)**: 가족 선택, 내 잔액, 상품 목록, 구매 요청, 문제집 완주 신고, 피스 보내기(양도), 최근 내역
- **엄마 화면(비밀번호)**: 요청 승인/거절, 문제집 장수 입력 → 자동 적립, 완주 보너스, 가족·잔액 관리, 상품 추가/수정/삭제·재고, 내역, 설정

처음 비밀번호는 `1234`입니다. 엄마 화면 › 설정에서 바꿔 주세요.

**알림**: 엄마 화면 › 설정 › ‘이 기기에서 알림 받기’를 켜면 가족의 구매 요청·완주 신고가 올 때 푸시 알림이 와요(Web Push, 별도 앱·계정 불필요). 아이폰은 홈 화면에 추가한 뒤 열어야 해요. 푸시용 키는 서버가 처음 켜질 때 만들어 저장소에 보관해요.

## 서버 (공유 저장소)

`server.js`는 설치할 것이 없는 Node.js(18+) 서버입니다. 사이트를 보여주고, 잔액·상품·내역을 저장해 모든 기기가 같은 데이터를 봅니다. 엄마 비밀번호는 서버에서 확인하고, 로그인하지 않은 가족은 구매 요청과 자기 요청 취소만 할 수 있어요.

저장소는 환경변수로 고릅니다.

| 환경변수 | 설명 |
| --- | --- |
| `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` | 있으면 Upstash Redis(무료)에 저장 — Render 같은 클라우드용 |
| `DATA_DIR` | 위 값이 없을 때 JSON 파일을 저장할 폴더 (기본 `./data`, git에 올라가지 않음) |
| `SEED_MEMBERS` | 처음 만들 때 넣을 가족과 시작 피스. 예: `이름:100,이름:50` |
| `PORT` | 포트 (기본 3000, Render는 자동) |

### 내 컴퓨터에서 켜기

```bash
node server.js
```

처음 한 번 `npm install`이 필요해요(`start-server.bat`은 알아서 해 줘요). Windows에서는 `start-server.bat`을 더블클릭해도 됩니다. 같은 와이파이의 가족 기기용 주소도 함께 나옵니다. 컴퓨터가 켜져 있어야 접속할 수 있어요.

### Render에 올리기 (24시간 접속)

1. [Upstash](https://upstash.com)에서 Redis 데이터베이스를 만들고 REST 주소와 토큰을 복사합니다.
2. Render에서 이 저장소로 **New › Blueprint**를 만들면 `render.yaml`을 읽어 서버가 만들어집니다.
3. 물어보는 환경변수 3개(`UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`, `SEED_MEMBERS`)를 입력합니다.
4. 배포가 끝나면 나오는 `https://….onrender.com` 주소를 가족에게 알려 줍니다.

Render 무료 서버는 15분 동안 접속이 없으면 잠들어서 다음 첫 접속에 약 1분 걸려요. 데이터는 Upstash에 있어서 잠들어도 사라지지 않아요.

GitHub Pages 주소는 서버 없이 열리므로 그 기기에만 저장하는 모드로 동작해요.

## 기획서에서 정해지지 않은 항목의 기본값

| 항목 | 이 페이지의 기본값 |
| --- | --- |
| 남는 장수 처리 | 다음 입력에 이월 (설정에서 버림으로 변경 가능) |
| 간식 종류와 가격 | 예시 상품으로 시작, 엄마 화면에서 수정 |
| 피스 가족 간 송금(양도) | 엄마 승인 없이 가족끼리 바로 가능, 엄마 설정에서 허용/막기 |
| 환전 상품 | 분류만 준비, 상품은 없음 |
| 데이터 저장 방식 | 서버 공유 저장소 (서버가 없으면 localStorage) + 백업 파일 |
| 비밀번호 보안 수준 | 서버 모드에서는 서버가 엄마 권한 확인, 로컬 모드는 브라우저 잠금 |
| 재고 소진 시 | 품절 표시, 구매 요청 불가 |
